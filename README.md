#  Fake News Detection AI

## Overview

This project is a Machine Learning and Natural Language Processing (NLP) based web application that detects whether a given news article is **REAL** or **FAKE**. The application processes the user's input text, converts it into numerical features using TF-IDF, and uses a trained Logistic Regression model to make the prediction.

##  Technologies Used

* **Python**
* **Machine Learning**
* **Natural Language Processing (NLP)**
* **Scikit-learn**
* **Pandas**
* **NumPy**
* **Regex**
* **Flask**
* **HTML5**
* **CSS3**

## How It Works

1. The user enters news text through the web interface.
2. The text is cleaned using basic NLP preprocessing techniques.
3. TF-IDF Vectorization converts the text into numerical features.
4. The trained Logistic Regression model processes these features.
5. The application predicts whether the news is **REAL** or **FAKE**.
6. The prediction is displayed through the Flask web interface.

##  Features

* Fake and real news classification
* NLP-based text preprocessing
* TF-IDF feature extraction
* Logistic Regression classification
* Flask-based web application
* Interactive user interface
* Real-time prediction

##  Project Structure

* `app.py` — Flask application and prediction logic
* `index.html` — Web interface
* `style.css` — Styling for the web interface
* Dataset/model files — Used for training and prediction

##  Project Purpose

The purpose of this project is to apply Machine Learning and NLP techniques to a real-world problem and develop a simple web application for detecting potentially fake news.
